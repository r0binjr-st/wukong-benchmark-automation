# OCR models

`eng.traineddata` and `rus.traineddata` are unmodified models from
[tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast),
commit `87416418657359cb625c412a48b6e1d6d41c29bd`.

The models are distributed under the Apache License 2.0; see `LICENSE`.
Only the LSTM engine is supported. The project uses the
[Tesseract .NET wrapper](https://github.com/charlesw/tesseract) through NuGet.
